# Ashby Wiki

Welcome to the Ashby Wiki: a living textbook for clear, first-principles engineering notes.

## Textbook

Start with the [textbook index](textbook/README). Each chapter is written for reuse: definitions first, assumptions stated, units kept visible, and worked examples included when they clarify the idea.

### Visual electronics primer

- [Transformers](textbook/transformers) — turns ratios, flux, regulation, and frequency response.
- [Resistors](textbook/resistors) — Ohm's law, networks, power, and thermal derating.
- [Op-amps](textbook/op-amps) — feedback, ideal rules, common circuits, and bandwidth.

## How this site is maintained

Notes are authored in the `content/` Obsidian vault and published with Quartz 4 through GitHub Pages. Drafts and working areas are intentionally excluded from the rendered site, but the repository is public: excluded notes remain readable in GitHub source.
