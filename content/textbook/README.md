# Textbook

This is the Ashby Wiki textbook landing page. Chapters will be added beneath this folder as they are reviewed and formatted.

## Reading conventions

- Quantities use SI units unless a note says otherwise.
- Equations use LaTeX and define symbols before using them.
- A `[VERIFY]` marker identifies a claim that still needs a source or measurement check.
- Diagrams are authored in Excalidraw and published as SVG exports in `content/attachments/diagrams/`.
